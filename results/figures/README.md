# Curated experiment figures

This directory contains the small, path-free figures selected for the project record:

- `training_curves/`: one training-curve image for each completed 2D, single-modality 3D, and four-modality 3D experiment.
- `../thesis_metric_comparison.png`: Dice and IoU comparison for the completed experiments.

The full local `artifacts/` directories remain ignored because they contain checkpoints, manifests, predictions, and other machine-local outputs. Raw BraTS data, model weights, and patient-case visualizations are not copied into this tracked directory.
